# White Paper Quiz

A single self-contained HTML file (`index.html`) that turns any white paper into a
20-question multiple choice quiz, entirely in the browser. No server, no API key,
no AI calls — questions are generated by pulling key terms, numbers, and named
entities directly out of the paper's own sentences and blanking them out. The
explanation shown after each answer is always the original sentence, verbatim.

This is a standalone tool, unrelated to the MemPalace memory system in the rest
of this repo.

## How it works

1. Open `index.html` on your phone (see below for how to get it there).
2. Paste the white paper text into the text box, or upload a `.txt`, `.md`, or
   `.pdf` file.
3. Tap **Generate Quiz**. The app extracts sentences, picks a number/term/phrase
   in each one to blank out, and builds 4-choice questions with 3 distractors
   pulled from elsewhere in the same document.
4. Tap a choice. You'll see whether you were right, the correct answer, and the
   full original sentence as the explanation.
5. Tap **Next Question** to continue. After 20 questions, your final score is
   shown.

PDF text extraction uses [pdf.js](https://mozilla.github.io/pdf.js/) loaded from
a CDN, so it requires an internet connection the first time. Pasting text or
uploading `.txt`/`.md` works fully offline.

## Getting it onto your phone

Since it's a single file with no server, pick whichever is easiest for you:

- **Email/AirDrop/cloud drive**: send yourself `index.html` and open it from
  your phone's Files app — most mobile browsers will render it directly.
- **Local network**: run `python3 -m http.server 8000` from this folder on your
  computer, then visit `http://<your-computer's-LAN-IP>:8000` from your phone's
  browser while on the same WiFi.

## Notes

- Works best on white papers with at least a few hundred words of prose — very
  short or mostly-numeric documents may not yield a full 20 questions.
- Nothing is uploaded anywhere; the text never leaves the browser tab except for
  the PDF.js library script itself (loaded from a CDN, not your document).
